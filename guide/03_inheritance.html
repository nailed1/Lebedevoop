Тема 03

Наследование

Как строить иерархии классов, переиспользовать код и выражать отношение «является» между объектами.

Что такое наследование

Наследование позволяет создать новый класс (производный, дочерний) на основе существующего (базового, родительского). Производный класс наследует поля и методы базового и может добавлять свои или переопределять существующие.

Отношение "является" (is-a)

Наследование выражает: «Круг является Фигурой», «Парабола является Функцией», «Конь является Фигурой (шахматной)». Если нет такого отношения — наследование неуместно.

Синтаксис наследования

Базовый синтаксис
class Base {
protected:                  // доступно наследникам
    int x;
public:
    void hello() { /* ... */ }
};

class Derived : public Base {  // ← публичное наследование
public:
    void world() {
        x = 5;  // OK — protected доступен наследнику
    }
};

Типы наследования

Типpublic базовогоprotected базовогоКогда использовать
public→ public→ protectedВыражает is-a отношение (чаще всего)
protected→ protected→ protectedРедко
private→ private→ privateРеализация через наследование (not is-a)

Иерархия геометрических фигур

Файл geometrical_figures/figures.h — отличный пример иерархии:

Figure (абстрактный базовый класс)
├── Circle<T> ← круг
├── Ellipse<T> ← эллипс
├── Triangle<T> ← треугольник (формула Герона)
├── Rectangle<T> ← прямоугольник
└── Polygon<T> ← многоугольник (формула Гаусса)
geometrical_figures/figures.h
// Базовый класс — определяет интерфейс
class Figure {
public:
    virtual double calc_area()      const = 0;  // чисто виртуальные
    virtual double calc_perimeter() const = 0;
    virtual ~Figure() = default;   // виртуальный деструктор!
};

// Производный класс
template<typename T>
class Circle : public Figure {
private:
    Point<T> center;
    double   radius;
public:
    Circle(Point<T> c, double r) : center(c), radius(r) {}

    // Переопределяем методы базового класса
    double calc_area()      const override { return M_PI * radius * radius; }
    double calc_perimeter() const override { return 2 * M_PI * radius; }
};

Иерархия математических функций

Файл function/Function.h — ещё один пример. Базовый класс предоставляет общие алгоритмы (интегрирование, дифференцирование), а наследники переопределяют только calculate():

Function (абстрактный)
├── Parabola ← ax² + bx + c
├── Hiperbola ← k/x
├── Exponenta ← a·e^(bx)
└── Polinom ← многочлен степени n
function/Function.h
class Function {
public:
    // Чисто виртуальные — ОБЯЗАНЫ переопределить наследники
    virtual double calculate(double x) const = 0;
    virtual void   print(double x)    const = 0;

    // Невиртуальные методы с дефолтной реализацией
    // Используют calculate() — шаблонный метод!
    virtual double integrate(double a, double b, int n = 1000) const;
    virtual double differential(double x, double h = 0.0001)   const;
    virtual double findMin(double a, double b) const;
    virtual double findMax(double a, double b) const;
    virtual ~Function() = default;
};
function/Parabola.h — производный класс
class Parabola : public Function {
private:
    double a, b, c;  // коэффициенты ax² + bx + c
public:
    Parabola(double a, double b, double c) : a(a), b(b), c(c) {}

    // Достаточно переопределить только эти два метода
    double calculate(double x) const override { return a*x*x + b*x + c; }
    void   print(double x)    const override;

    // integrate(), differential(), findMin(), findMax() — унаследованы!
};

Иерархия шахматных фигур

Figure (базовый)
├── King ← Король
├── Queen ← Ферзь
├── Rook ← Ладья
├── Bishop ← Слон
├── Knight ← Конь
└── Pawn ← Пешка
chess/figures.h
class Figure {
protected:
    Color     color;    // WHITE / BLACK
    PieceType type;
    bool      hasMoved; // для рокировки и взятия на проходе
public:
    virtual char getSymbol() const = 0;
    virtual std::vector<Position> getPseudoMoves(
        int r, int c, const Table& t) const = 0;
    virtual ~Figure() = default;
    Color getColor() const { return color; }
};

class King : public Figure {
public:
    King(Color c) { color = c; type = PieceType::King; }
    char getSymbol() const override { return 'K'; }
    std::vector<Position> getPseudoMoves(int, int, const Table&) const override;
};

Вызов конструктора базового класса

Производный класс должен инициализировать базовый класс через его конструктор:

Вызов конструктора базового класса
class Animal {
protected:
    std::string name;
public:
    Animal(const std::string& n) : name(n) {}
};

class Dog : public Animal {
private:
    int age;
public:
    // Сначала вызываем конструктор Animal, потом инициализируем age
    Dog(const std::string& n, int a) : Animal(n), age(a) {}
};

Тест для самопроверки

6 вопросов
Вопрос 1

Что означает class Dog : public Animal?

Публичное наследование (: public Base) — самый распространённый вид. Оно означает отношение "является": Dog является Animal. Публичные и protected члены Animal остаются с теми же правами доступа в Dog.
Вопрос 2

К каким полям базового класса имеет доступ производный класс?

Производный класс имеет доступ к public и protected членам базового. private члены скрыты даже от наследников — это важная часть инкапсуляции.
Вопрос 3

Почему в классе Function метод integrate() не является чисто виртуальным, хотя calculate() — чисто виртуальный?

Это паттерн Template Method: базовый класс предоставляет алгоритм (метод трапеций), который внутри вызывает calculate(). Наследники определяют только calculate(), а интегрирование работает автоматически.
Вопрос 4

Как вызвать конструктор базового класса из производного?

Конструктор базового класса вызывается из списка инициализации производного конструктора. Если не вызвать явно, компилятор вызовет конструктор по умолчанию базового — и если его нет, будет ошибка компиляции.
Вопрос 5

В иерархии геометрических фигур Circle : public Figure. Что произойдёт при вызове f.calc_area() через указатель Figure* f = new Circle(...)?

Виртуальные функции (virtual) разрешаются динамически — в runtime по реальному типу объекта, а не по типу указателя. Это и есть полиморфизм. О нём подробнее — в следующей теме.
Вопрос 6

Какие из следующих утверждений о ключевом слове override верны?

override — необязательный, но полезный спецификатор (C++11). Если написать void foo() override, а в базовом классе нет virtual foo() с такой же сигнатурой — ошибка компиляции. Это защищает от опечаток.
