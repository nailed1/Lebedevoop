Рациональные числа

Полноценный класс-пример: НОД, инварианты, проверка переполнения, решение квадратного уравнения.

Файлы
class_Rational/rational.h, rational.cpp, main_rational.cpp

Что такое рациональное число

Рациональное число — дробь вида p/q, где p (числитель) и q (знаменатель) — целые числа, q ≠ 0. Класс Rational представляет дробь точно, без потери точности (в отличие от double).

Инварианты класса

Инварианты — условия, которые всегда верны для корректного объекта:

  • den > 0 — знаменатель всегда положительный
  • Дробь всегда сокращена (НОД(num, den) == 1)
class_Rational/rational.cpp — поддержание инвариантов
Rational::Rational(long long n, long long d) {
    if (d == 0)
        throw std::invalid_argument("Denominator cannot be zero");

    // Инвариант 1: den > 0 — переносим знак в числитель
    if (d < 0) { n = -n; d = -d; }

    num = n;
    den = d;
    simplify();  // Инвариант 2: сокращение через НОД
}

// Алгоритм Евклида для НОД
void Rational::simplify() {
    long long g = gcd(std::abs(num), den);
    num /= g;
    den /= g;
}

// Вычисление НОД (Greatest Common Divisor)
long long gcd(long long a, long long b) {
    while (b != 0) {
        long long t = b;
        b = a % b;
        a = t;
    }
    return a;
}

Проверка переполнения

Арифметика с дробями легко вызывает переполнение long long. Класс проверяет это заранее:

class_Rational/rational.cpp — защита от переполнения
// Проверяем: a + b вызовет переполнение?
static bool will_add_overflow(long long a, long long b) {
    if (b > 0 && a > std::numeric_limits<long long>::max() - b) return true;
    if (b < 0 && a < std::numeric_limits<long long>::min() - b) return true;
    return false;
}

// Проверяем: a * b вызовет переполнение?
static bool will_mul_overflow(long long a, long long b) {
    if (a == 0 || b == 0) return false;
    long long result = a * b;
    return (result / a != b);  // проверяем через обратное деление
}

// Использование в operator+=
Rational& Rational::operator+=(const Rational& r) {
    if (will_mul_overflow(num, r.den) ||
        will_mul_overflow(r.num, den)  ||
        will_add_overflow(num * r.den, r.num * den))
        throw std::overflow_error("Overflow in operator+=");
    // ... безопасная операция ...
}

Применение: решение квадратного уравнения

В main_rational.cpp класс Rational используется для точного решения квадратных уравнений с рациональными коэффициентами:

class_Rational/main_rational.cpp
// Решаем ax² + bx + c = 0
void solveQuadratic(Rational a, Rational b, Rational c) {
    // Дискриминант: D = b² - 4ac
    Rational D = b * b - Rational(4) * a * c;

    if ((double)D < 0) {
        std::cout << "Корней нет\n";
        return;
    }

    // Если D — точный квадрат рационального числа
    double sqrtD = std::sqrt((double)D);
    Rational two_a = Rational(2) * a;

    // x = (-b ± √D) / (2a)
    std::cout << "x1 = " << (-b + Rational((long long)sqrtD)) / two_a << "\n";
    std::cout << "x2 = " << (-b - Rational((long long)sqrtD)) / two_a << "\n";
}

Тест для самопроверки

5 вопросов
Вопрос 1

Зачем в конструкторе Rational(n, d) при d < 0 выполняется n = -n; d = -d;?

Инвариант класса: den > 0. При Rational(-1, -2): оба отрицательны, в итоге 1/2. При Rational(1, -2): знак переходит в числитель, получаем -1/2. Это упрощает сравнение и вычисления.
Вопрос 2

Зачем после каждой операции вызывается simplify()?

Если не сокращать, числа быстро растут. Например, складывая дроби 50 раз подряд, числитель и знаменатель могут переполниться. Сокращение через НОД поддерживает числа маленькими и упрощает сравнение.
Вопрос 3

Зачем operator double() помечен как explicit?

Без explicit: Rational r(1,3); double d = r; — скомпилируется незаметно. С explicit: нужно явно написать double d = (double)r; или static_cast<double>(r). Это документирует намерение и предупреждает о потере точности.
Вопрос 4

Почему числитель и знаменатель хранятся как long long, а не int?

При сложении a/b + c/d = (a*d + c*b)/(b*d). Если a, b, c, d ~ INT_MAX, то a*d вызовет переполнение int. long long даёт 64 бита вместо 32, что значительно расширяет безопасный диапазон.
Вопрос 5

В чём преимущество класса Rational перед типом double для решения уравнений?

double — число с плавающей точкой, хранит только приближение. 1.0/3.0 * 3.0 != 1.0 из-за ошибок округления. Rational хранит числитель и знаменатель целыми числами — Rational(1,3) * 3 == 1 точно.
