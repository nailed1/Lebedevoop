Тема 07

Управление памятью

Stack vs. heap, new/delete, утечки памяти, глубокое копирование и умные указатели.

Stack (стек) vs. Heap (куча)

ХарактеристикаStack (стек)Heap (куча)
ВыделениеАвтоматически при объявленииЯвно через new
ОсвобождениеАвтоматически при выходе из блокаЯвно через delete
РазмерОграничен (несколько МБ)Ограничен RAM
СкоростьБыстрееМедленнее

Stack vs Heap
void example() {
    Array a(5);           // Стек — уничтожится при выходе из функции
    Array* b = new Array(5); // Куча — нужно вызвать delete!
    delete b;              // Явное освобождение
}  // a уничтожается здесь автоматически

// Массив объектов в куче:
int* arr = new int[10];   // new[]
delete[] arr;               // delete[] — пара к new[]!
Главные ошибки
  • Утечка памяти — забыли вызвать delete
  • Висячий указатель — используем указатель после delete
  • Double free — вызвали delete дважды
  • Несоответствие new/delete — new[] надо удалять delete[]

Динамический массив: полный пример

Класс Array — учебный пример ручного управления памятью:

class_array/array.cpp — полный цикл жизни памяти
// Конструктор — выделение
Array::Array(int sz) : size(sz), capacity(sz) {
    ptr = new int[capacity];  // выделяем в куче
    for (int i = 0; i < size; i++) ptr[i] = 0;
}

// Деструктор — освобождение
Array::~Array() {
    delete[] ptr;      // освобождаем
    ptr = nullptr;    // обнуляем — защита от double-free
}

// Увеличение ёмкости (внутренний метод)
void Array::increaseCapacity(int newCapacity) {
    int* newPtr = new int[newCapacity];   // новый блок
    for (int i = 0; i < size; i++)
        newPtr[i] = ptr[i];               // копируем данные
    delete[] ptr;                         // освобождаем старый блок
    ptr      = newPtr;
    capacity = newCapacity;
}

// Вставка — при необходимости расширяем
void Array::insert(int elem, int index) {
    if (size == capacity)
        increaseCapacity(capacity * 2);  // удвоение ёмкости
    for (int i = size; i > index; i--)
        ptr[i] = ptr[i - 1];           // сдвигаем вправо
    ptr[index] = elem;
    size++;
}

Глубокое vs. поверхностное копирование

Поверхностное (плохо) vs. глубокое (хорошо)
// Поверхностное копирование (по умолчанию)
// a.ptr и b.ptr указывают на ОДИН блок памяти!
Array a(5);
Array b_shallow = a;  // без конструктора копирования: b.ptr == a.ptr

// Глубокое копирование (правильно — из array.cpp)
Array::Array(const Array& arr) {
    size     = arr.size;
    capacity = arr.capacity;
    ptr      = new int[capacity];  // новый блок!
    for (int i = 0; i < size; i++)
        ptr[i] = arr.ptr[i];         // копируем данные
    // Теперь b.ptr != a.ptr — независимые массивы
}

RAII — Resource Acquisition Is Initialization

Идиома RAII: ресурс захватывается в конструкторе и освобождается в деструкторе. Это гарантирует корректное освобождение даже при исключениях.

RAII в классе Array
Array arr(100);  // конструктор: выделяет память
try {
    // ... работаем с arr ...
    throw std::runtime_error("ошибка!");
} catch (...) {
    // arr.~Array() АВТОМАТИЧЕСКИ вызовется при раскрутке стека
    // Утечки памяти не будет!
}

Умные указатели (C++11+)

В шахматах (chess/table.h) используются unique_ptr — умные указатели, которые автоматически освобождают память:

chess/table.h — unique_ptr
#include <memory>

class Table {
    // unique_ptr — единственный владелец объекта
    // При уничтожении Table — все Figure удалятся автоматически!
    std::vector<std::unique_ptr<Figure>> pieces;
public:
    void addPiece(Color c, PieceType t) {
        // make_unique создаёт объект и оборачивает в unique_ptr
        pieces.push_back(std::make_unique<King>(c));
    }
    // Деструктор НЕ нужен — unique_ptr сделает всё сам
};

// Сравнение: ручное vs. умное управление
Figure* raw = new King(Color::White);  // нужен delete
delete raw;

auto smart = std::make_unique<King>(Color::White); // само освободится

unique_ptr не копируется!

Именно поэтому в шахматах написан конструктор копирования для Table — надо вручную создавать новые unique_ptr:

chess/table.cpp — копирование при уникальных указателях
Table::Table(const Table& other) {
    for (const auto& p : other.pieces) {
        // unique_ptr нельзя скопировать — создаём новый объект
        pieces.push_back(p->clone());  // метод clone() создаёт копию Figure
    }
}

Тест для самопроверки

6 вопросов
Вопрос 1

Что такое "утечка памяти"?

Утечка памяти: программа выделила память в куче через new, но никогда не освободила через delete. Память остаётся занятой до завершения процесса. Накопленные утечки могут привести к исчерпанию памяти.
Вопрос 2

Что произойдёт если вызвать delete вместо delete[] для массива?

delete[] сообщает компилятору, что нужно вызвать деструктор для каждого элемента массива. delete вызовет деструктор только для первого. Это undefined behavior — результат непредсказуем.
Вопрос 3

В чём суть идиомы RAII?

RAII (Resource Acquisition Is Initialization): привязываем жизнь ресурса к жизни объекта. Конструктор захватывает, деструктор освобождает. C++ гарантирует вызов деструктора при выходе из области видимости — даже при исключениях.
Вопрос 4

Чем unique_ptr отличается от сырого указателя?

unique_ptr — RAII-обёртка над сырым указателем. При выходе из области видимости или при присваивании нового значения — автоматически вызывает delete. Не допускает копирования (только перемещение), гарантируя единственного владельца.
Вопрос 5

Метод increaseCapacity в классе Array выделяет новый блок, копирует данные, затем удаляет старый. Что будет, если изменить порядок: сначала удалить старый, потом выделить новый?

При new возможно исключение std::bad_alloc если памяти недостаточно. Правильный порядок: сначала выделить новое, скопировать, потом удалить старое. Если new кинет исключение — старые данные сохраняются, объект остаётся рабочим.
Вопрос 6

Почему в шахматах написан явный конструктор копирования для Table, хотя unique_ptr должен управлять памятью автоматически?

unique_ptr запрещает копирование (только перемещение) — у него единственный владелец. Чтобы скопировать Table (нужно для ИИ: симулировать ходы на копии), нужно явно создавать новые объекты Figure через метод clone().
