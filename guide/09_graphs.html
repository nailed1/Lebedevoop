Графы: BFS, DFS, Дейкстра

Граф из классов, обход в ширину и глубину, алгоритм кратчайшего пути — всё через ООП.

Архитектура графа

В graph/ граф представлен тремя слоями классов, связанных через friend:

Graph ← владеет узлами, загружает из файла
├── Node ← узел (вершина) с именем и соседями
│ └── neighbours ← map<Node*, int> (сосед → вес ребра)
├── BFS ← обход в ширину (friend Node)
├── DFS ← обход в глубину (friend Node)
└── Dijkstra ← кратчайший путь (friend Node)

Класс Node

graph/graph.h — класс Node
class Node {
private:
    std::string name;
    std::map<Node*, int> neighbours; // смежные узлы + вес ребра

public:
    Node(const std::string& name) : name(name) {}

    const std::string& getName() const { return name; }
    void addNeighbour(Node* n, int weight) { neighbours[n] = weight; }

    // Итераторы для обхода соседей
    using neighbour_iterator = std::map<Node*,int>::const_iterator;
    neighbour_iterator nb_begin() const { return neighbours.begin(); }
    neighbour_iterator nb_end()   const { return neighbours.end(); }

    // Алгоритмы — друзья: они могут читать приватный neighbours
    friend class BFS;
    friend class DFS;
    friend class Dijkstra;
};

BFS — Обход в ширину

BFS (Breadth-First Search) — исследует граф "слоями", начиная от стартового узла. Использует очередь (std::queue).

graph/BFS.cpp — алгоритм BFS
// Проверка связности двух вершин
bool BFS::connected(Node* begin, Node* end) {
    if (begin == end) return true;

    std::set<Node*>   visited;   // посещённые вершины
    std::queue<Node*> queue;     // очередь для BFS

    queue.push(begin);
    visited.insert(begin);

    while (!queue.empty()) {
        Node* current = queue.front();
        queue.pop();

        // Перебираем всех соседей текущего узла
        for (auto it = current->nb_begin(); it != current->nb_end(); ++it) {
            Node* neighbor = it->first;
            if (neighbor == end) return true;  // нашли!
            if (visited.count(neighbor) == 0) {
                visited.insert(neighbor);
                queue.push(neighbor);
            }
        }
    }
    return false;
}

DFS — Обход в глубину

DFS (Depth-First Search) — идёт как можно глубже прежде чем вернуться. Реализован рекурсивно.

graph/DFS.cpp — рекурсивный DFS
bool DFS::connected(Node* begin, Node* end) {
    std::set<Node*> visited;
    return dfs_helper(begin, end, visited);
}

bool DFS::dfs_helper(Node* current, Node* target,
                       std::set<Node*>& visited) {
    if (current == target) return true;
    visited.insert(current);

    for (auto it = current->nb_begin(); it != current->nb_end(); ++it) {
        Node* neighbor = it->first;
        if (visited.count(neighbor) == 0) {
            if (dfs_helper(neighbor, target, visited))
                return true;  // рекурсивный вызов
        }
    }
    return false;
}

Алгоритм Дейкстры

Находит кратчайший путь от стартовой вершины до целевой в графе с неотрицательными весами рёбер.

graph/dijkstra.cpp — алгоритм Дейкстры
struct MarkedNode {
    Node* node;
    int   dist;    // расстояние от старта
    Node* prev;    // предыдущий узел (для восстановления пути)

    // Для priority_queue: меньшее расстояние — больший приоритет
    bool operator>(const MarkedNode& o) const { return dist > o.dist; }
};

Way Dijkstra::shortestWay(Node* begin, Node* end) {
    // priority_queue: MinHeap — узел с минимальным расстоянием первый
    std::priority_queue<MarkedNode,
                        std::vector<MarkedNode>,
                        std::greater<MarkedNode>> pq;

    std::map<Node*, int>   dist;  // кратчайшие расстояния
    std::map<Node*, Node*> prev;  // предшественники для пути

    dist[begin] = 0;
    pq.push({begin, 0, nullptr});

    while (!pq.empty()) {
        auto [node, d, p] = pq.top(); pq.pop();

        if (d > dist[node]) continue; // устаревшая запись

        for (auto it = node->nb_begin(); it != node->nb_end(); ++it) {
            Node* nb     = it->first;
            int   newDist = d + it->second;

            if (dist.count(nb) == 0 || newDist < dist[nb]) {
                dist[nb] = newDist;
                prev[nb] = node;
                pq.push({nb, newDist, node});
            }
        }
    }

    // Восстановление пути
    Way way;
    for (Node* n = end; n != nullptr; n = prev.count(n) ? prev[n] : nullptr)
        way.nodes.push_front(n);
    way.totalDist = dist.count(end) ? dist[end] : -1;
    return way;
}

Сравнение алгоритмов

АлгоритмСтруктура данныхПрименениеСложность
BFSОчередь (queue)Кратчайший путь в невзвешенном графе, компоненты связностиO(V + E)
DFSСтек (рекурсия)Достижимость, топологическая сортировка, циклыO(V + E)
DijkstraПриоритетная очередьКратчайший путь во взвешенном графе (веса ≥ 0)O((V+E) log V)

Паттерны ООП в графе

  • Friend classes — BFS, DFS, Dijkstra являются друзьями Node: могут читать приватный map соседей
  • Strategy pattern — три разных алгоритма обхода с одинаковым интерфейсом (connected())
  • Iterator pattern — итераторы nb_begin() / nb_end() для обхода соседей без раскрытия внутренней структуры

Тест для самопроверки

6 вопросов
Вопрос 1

Какую структуру данных использует BFS?

BFS использует очередь: добавляет соседей в конец, обрабатывает с начала. Это обеспечивает обход "слоями" — сначала все вершины на расстоянии 1, потом 2 и т.д.
Вопрос 2

Почему алгоритм Дейкстры не работает с отрицательными весами?

Дейкстра помечает вершину как "обработанную" когда извлекает из очереди. При отрицательных весах может существовать более короткий путь через ещё не обработанные вершины. Для отрицательных весов используется алгоритм Беллмана-Форда.
Вопрос 3

Зачем в Дейкстре есть проверка if (d > dist[node]) continue;?

При обнаружении более короткого пути мы добавляем вершину в очередь снова (с новым расстоянием), не удаляя старую запись. Проверка пропускает обработку, если расстояние в очереди больше уже найденного оптимального.
Вопрос 4

Зачем классы BFS, DFS, Dijkstra объявлены как friend для Node?

Инкапсуляция: поле neighbours скрыто от произвольного внешнего кода. Но алгоритмы должны его читать. Friend-объявление даёт доступ именно этим классам, не открывая поле для всех. Это контролируемый обход инкапсуляции.
Вопрос 5

DFS реализован рекурсивно. В чём риск глубокой рекурсии?

Каждый рекурсивный вызов занимает память стека. Для очень глубоких графов (много тысяч уровней) это может вызвать stack overflow. Итеративный DFS с явным стеком (std::stack) лишён этого ограничения.
Вопрос 6

Какую роль играет std::set<Node*> visited в алгоритмах обхода?

В графе могут быть циклы. Без отслеживания посещённых вершин обход зациклился бы. visited хранит уже обработанные вершины — перед добавлением в очередь/стек проверяем, не была ли вершина уже посещена.
