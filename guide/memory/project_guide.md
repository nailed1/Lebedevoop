Создан интерактивный HTML справочник в /LebedevOopCpp/guide/.

**Why:** Пользователь попросил создать пособие по репозиторию курса ООП (Лебедев), C++, с тестами самопроверки.

**How to apply:** Не трогать файлы в guide/ — это готовый справочник. При добавлении новых тем в репо — можно предложить добавить страницу в guide/.

Структура:
- index.html — главная
- 01–12 — 12 тематических страниц
- css/style.css — единые стили (тёмная тема)
- js/quiz.js — движок тестов

Покрытые темы: классы, конструкторы, наследование, полиморфизм, шаблоны, перегрузка операторов, управление памятью, связные списки, графы (BFS/DFS/Дейкстра), Rational, DateTime, игры (4рaws/chess).
